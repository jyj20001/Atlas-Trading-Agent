## 五、假设与限制

### 实盘约束
- **T+1 限制**: 买入当日不可卖出
- **涨停无法买入**: 买入价 >= 涨停价时本轮跳过
- **一字涨停**: 开盘即涨停且成交量<10万股时过滤
- **跌停无法卖出**: 止损日若跌停则延迟至可卖日
- **开盘跳空风险**: 成交价 = max(突破价, 开盘价) × (1+滑点)
- **成交量/价格为零的交易日**: 跳过（停牌/休市）

### 数据源
- **K线**: Tencent API via market_fetcher (含 SQLite 缓存)
- **基本面**: announcement_snapshot (暂未回填历史数据 → score=0)
- **市场环境**: market_snapshot (6000行, 2018~2026, snapshot_query)
- **板块强度**: sector_snapshot (API限制未全量回填 → score≈0)
- **历史过滤**: 所有数据通过 `available_time <= signal_date` 严格过滤

### 简化
- 使用前 200 只市值最大的股票作为样本（非全市场 4467 只）
- 无风险利率: 2% 年化（用于夏普比率）
- 滑点: 千1（单边）
- 佣金: 万2.5 + 印花税千1（卖出）
