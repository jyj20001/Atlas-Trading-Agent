**日期:** 2026-07-25
**目标:** 将 K 线覆盖扩展到 2018-01-01 以后

## 核心发现: 腾讯 API 个股 K 线硬限制

### 验证结果

| 股票 | 代码 | 请求天数 | 实际返回 | 最早日期 | 最新日期 |
|------|:----:|:--------:|:--------:|:--------:|:--------:|
| 浦发银行 | 600000 | 2000 | **640** | 2023-12-01 | 2026-07-24 |
| 平安银行 | 000001 | 2000 | **640** | 2023-12-01 | 2026-07-24 |
| 宁德时代 | 300750 | 2000 | **640** | 2023-12-01 | 2026-07-24 |
| 贵州茅台 | 600519 | 2000 | **640** | 2023-12-01 | 2026-07-24 |
| 五粮液 | 000858 | 2000 | **640** | 2023-12-01 | 2026-07-24 |
| 海康威视 | 002415 | 2000 | **640** | 2023-12-01 | 2026-07-24 |
| 金山办公 | 688111 | 2000 | **640** | 2023-12-01 | 2026-07-24 |

**结论: 所有 A 股个股通过腾讯 `fqkline/get` 接口最多返回 640 根日 K 线，约 2.5 年。**

### 原因分析

腾讯 API 的 `qfq`（前复权）参数触发了服务器端的数据截断：

| 数据维度 | 支持长度 | 原因 |
|---------|:--------:|------|
| 个股 K 线 (`qfqday`) | **最多 640 根** | 前复权计算需要全量历史，服务器限制计算深度 |
| 指数 K 线 (`qfqday`) | **可达 2000+ 根** | 指数无复权问题，直接返回原始数据 |
| 个股未复权 (`day`) | 无数据（此端点） | `fqkline/get` 端点无未复权数据 |

**无法通过此 API 覆盖 2019-2023 的个股 K 线。**

## 替代方案

| 方案 | 可行性 | 工作量 |
|------|:------:|:------:|
| 改用 `day`（未复权）+ 本地复权 | 需验证腾讯其他端点 | 高 |
| 改用新浪 K 线 API | 需调研可用性 | 中 |
| 使用东方财富/其他数据源 | 需开发新数据源 | 高 |
| 使用富途牛牛本地进程 | 可行（已有 MCP），需批量处理 | 中 |
| **接受当前限制** | **立即可用** | **零** |

### 推荐: 接受当前限制

当前 640 根 K 线 + 2.5 年覆盖是 Baseline 的有效数据范围。

策略在 2024-2026 市场环境中已产出 **2957 条候选信号、129 笔交易、45.7% 胜率**。
